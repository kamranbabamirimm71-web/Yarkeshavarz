# بسته آفلاین کشاورزیار

این پوشه برای بانک دانش کشاورزی بدون اینترنت آماده شده است.

فایل‌ها:
- `agriculture-db.js` — بانک محصولات، آفات، بیماری‌ها، خاک، تغذیه، آبیاری، گلخانه، باغ، علف هرز، ماشین‌آلات، ایمنی، مدیریت و دام/طیور/زنبورداری.
- `offline-ai.js` — موتور جست‌وجوی فارسی و پاسخ آفلاین.

نکته مهم:
این بانک برای آموزش و راهنمایی عمومی است. دوز سموم و کودها نباید به صورت نسخه ثابت داخل برنامه فرض شود؛ برچسب محصول، ثبت کشور، آزمون خاک/آب و شرایط مزرعه ملاک هستند.

مرحله بعد در خود پروژه:
1. بارگذاری `offline/offline-ai.js` در نسخه اصلی.
2. اول تلاش برای پاسخ آنلاین.
3. در خطای اینترنت یا قطع شبکه، پاسخ از `offline/offline-ai.js`.
4. بعداً همین بانک را می‌توان به بانک‌های تخصصی بزرگ‌تر (محصولات، آفات، بیماری‌ها، کودها، گلخانه، باغ و تشخیص تصویری) گسترش داد.
