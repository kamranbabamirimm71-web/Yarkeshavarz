# صفحات یار کشاورز

رابط کاربری اصلی به‌صورت SPA در `index.html` اجرا می‌شود و رندر هر صفحه در `views.js` جدا نگه داشته شده است.

- `home` صفحه اصلی
- `lands` مدیریت زمین‌ها
- `add` ثبت زمین
- `openLand` پرونده زمین
- `cultivation` پرونده کشت و اقتصاد
- `inventory` انبار
- `weather` آب‌وهوا
- `manager` مدیر مزرعه
- `yar` کشاورزیار
- `profile` پروفایل
- `settings` تنظیمات
- `account` حساب
- `news` اخبار
- `ads` تبلیغات
- `equipment` ادوات
- `game` سرگرمی

برای تغییر منطق هر قابلیت، فایل متناظر در `modules/` را تغییر دهید؛ `index.html` فقط پوسته و نقطه ورود برنامه است.
