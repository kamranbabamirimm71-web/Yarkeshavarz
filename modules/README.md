# ماژول‌های یار کشاورز

منطق برنامه از پوسته جدا شده است:

- `app.js` هسته، وضعیت، ذخیره‌سازی و مسیریابی
- `land.js` زمین و اندازه‌گیری
- `inventory.js` انبار
- `cultivation.js` کشت، هزینه و درآمد
- `weather.js` آب‌وهوا
- `yar.js` کشاورزیار
- `game.js` بازی
- `equipment.js` ادوات
- `manager.js` مدیر مزرعه
- `settings.js` تنظیمات
- `backup.js` پشتیبان
- `fun.js` سرگرمی
- `offline-loader.js` بارگذاری موتور آفلاین

ماژول‌های `land-edit.js`، `land-plan.js`، `land-save-fix.js` و `land-schematic.js` به‌عنوان ابزارهای مستقل/سازگاری نگه داشته شده‌اند و بدون هماهنگی با هسته جدید به‌صورت خودکار لود نمی‌شوند.
